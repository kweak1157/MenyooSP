# 5 — Save loop nested Tick ✔ - Completed

Read `GLOBAL.md`. Do only this number.

## Where

- `Solution/source/Submenus/Spooner/FileManagement.cpp` (~1332)
- Pattern: `for (;;)` { `SpoonerMode::Tick();` … wait for waypoint }

## Problem

While a save waits for a waypoint, it pumps `SpoonerMode::Tick` in an infinite loop on the same fiber. That walks `EntityDb`, draws markers, and can fire the hotkey again.

## Fix

Wait for the waypoint without nested `SpoonerMode::Tick`. Use the normal main loop, or a wait that only checks the waypoint.

## Do not

- Do not break world/map save.
- Do not nest `Menu::Tick` or `SpoonerMode::Tick` inside save.
