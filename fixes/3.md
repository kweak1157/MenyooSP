## Problem

`GetEntityPtr` does `new SpoonerEntity`, then often `delete` and points into `EntityDb`. Aim/copy calls this often.

`get_prop_model_label` hashes every string in `objectModels` until it matches. That list is large.

## Fix

- If the ent is in `EntityDb`, return `&EntityDb[i]`. No heap.
- If it is not in the DB, fill a stack/local `SpoonerEntity`. No `new`.
- Build a hash → name map for `objectModels` once.

## Do not

- Do not change how Spooner stores ents.
- Do not leak or return a pointer to a dead temporary.
