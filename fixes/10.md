Read `GLOBAL.md`. Do only this number.

## Where

- `Solution/source/Memory/GTAmemory.cpp` `SpSnow::Tick` (~1638)
- `EnableSnow` (~1422) does `VirtualProtect` + patch

## Problem

If snow is on, `Tick` calls `EnableSnow(true)` each frame. Addresses are already cached. This is a kernel protect + write every frame.

## Fix

Patch once when snow turns on. Unpatch once when it turns off. `Tick` must not patch again if already applied.

## Do not

- Do not change how snow looks.
- Do not rescan patterns each frame.
