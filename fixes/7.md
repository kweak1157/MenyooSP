# 7 — Model Load WAIT on menu thread ✔ - Completed

Read `GLOBAL.md`. Do only this number.

## Where

- `Solution/source/Scripting/Model.cpp` `Load` (~331), `LoadAndWait`
- Callers: `Scripting/World.cpp` `CreatePed` / `CreateVehicle` (timeout 3000 / 7500)

## Problem

`Load` does `WAIT(0)` until the model is ready or the timeout ends (up to 3s or 7.5s). This stops the menu thread (and Spooner) for each spawn.

## Fix

Request the model and continue on later frames. Do not block `ThreadMenyooMain` for seconds.

## Do not

- Do not spawn an entity before the model is ready.
- Do not change the spawn result the player sees.
