# 2 — Spooner tick when Spooner is off ✔ - Completed

Read `GLOBAL.md`. Do only this number.

## Where

- `Solution/source/Submenus/Spooner/SpoonerMode.cpp` `Tick` (~884)
- Call: `Menu/Routine.cpp` `Menu::loops` (~2732)
- Markers: `Spooner/MarkerManagement.cpp` `DrawAll`
- Tasks: `Spooner/SpoonerTaskSequence.cpp` via `ent.TaskSequence.Tick`

## Problem

`Tick` always runs, even if Spooner is off:

- Hotkey
- `CamTick()` (enters, then early-out)
- `Exists()` on every `Databases::EntityDb` item
- `DrawAll` if any marker exists

A large map is slow while you only drive.

## Fix

- If Spooner is off: run the hotkey only.
- Run task ticks only if a sequence is live.
- Draw markers only when they must show (Spooner on, or a marker needs draw/teleport).
- Keep hotkey working when the menu is closed.

## Do not

- Do not stop Spooner camera, preview, or markers when the mode is on.
- Do not break task sequences that must run after you leave Spooner. If sequences must run while off, tick only those ents.
