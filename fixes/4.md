# 4 — Marker WAIT in draw tick - ✔ - Completed

Read `GLOBAL.md`. Do only this number.

## Where

- `Solution/source/Submenus/Spooner/MarkerManagement.cpp` `DrawAll` (~134–172)
- Called from `SpoonerMode::Tick` each frame when markers exist

## Problem

On marker teleport it does fade, `WAIT(20)`, teleport, `WAIT(100)`, fade in. This runs on the main script thread inside the per-frame tick. The trainer stops. Nested `WAIT` can re-enter ticks.

## Fix

Use a small state + elapsed time (fade out → teleport → fade in). Do not call `WAIT` from `DrawAll` or from `SpoonerMode::Tick`.

## Do not

- Do not change marker look or teleport result.
- Do not add `WAIT` on the main fiber.
